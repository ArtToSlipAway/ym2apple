# ym2apple

Проект для переноса избранного из Yandex Music в Apple Music с консервативным
сопоставлением треков, сохранением прогресса и проверкой результата.

Этот репозиторий — публичное описание и небольшой автономный пример.
Полная реализация развивается приватно. Здесь нет рабочего клиента музыкальных
сервисов, авторизации, личной музыкальной библиотеки или материалов реальной миграции.

## Подход

1. Прочитать метаданные исходных треков.
2. Найти кандидатов в доступном пользователю каталоге Apple Music.
3. Сравнить название, исполнителя, длительность и версию записи.
4. Оставить неоднозначные совпадения на ручную проверку.
5. Сохранить прогресс, добавить подтверждённые треки и сверить результат.

Несколько исходных записей могут соответствовать одному треку целевого каталога.
Повторный запуск должен учитывать уже добавленные записи. Неопределённый результат
сетевой записи требует сверки перед повторной отправкой.

## Минимальный пример

Python 3.11+, без сторонних зависимостей:

```sh
python3 demo.py --dry-run
python3 -m unittest -v
```

Пример использует только вымышленные записи, сравнивает точные нормализованные
названия и исполнителей, допускает разницу длительности до двух секунд и исключает
повторные целевые ID. Он ничего не читает из аккаунтов и ничего не отправляет в сеть.
Флаг `--dry-run` обязателен; режим записи отсутствует.

Ожидаемый результат: один новый целевой ID, одно неоднозначное совпадение и один
трек без совпадения. Это иллюстрация принципа, а не production matcher: она не
обрабатывает особенности релизов, ремиксов, транслитерацию или неполные метаданные.

## Статус

Публичный пакет v1.0 и полный исходный код здесь не распространяются.
Демонстрация не гарантирует доступность треков или успешность реального переноса.
Публичная лицензия на повторное использование пока не выбрана.
